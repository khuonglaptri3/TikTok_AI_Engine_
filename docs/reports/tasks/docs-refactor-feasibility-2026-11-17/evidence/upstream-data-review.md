# Upstream data feasibility review

- Review date: 2026-11-17 (Asia/Saigon).
- Scope: public repository metadata, bounded schema/provenance inspection, one complete metadata CSV aggregated in memory, and current local data availability. No TikTok crawling, provider calls, data changes, or repository clone.
- Upstream revision: [`f142e5656a220f94f8024de168b0832754b3bd9e`](https://github.com/TrggTin/21KHDL-TikTok-Analytics/tree/f142e5656a220f94f8024de168b0832754b3bd9e), default branch `main`, commit dated 2025-07-03.
- Machine-readable evidence: [upstream-metadata.json](upstream-metadata.json).

## Decision

The source supports a useful **historical Vietnamese creator/video metadata and script-reference demonstration**, subject to restoring the local data and validating machine-generated annotations. It does not supply a complete historical waveform corpus, viewer-comment corpus, manually verified ABSA/seeding labels, or repeated engagement observations. Those omissions prevent this source alone from validating voice prosody, viewer trust, undisclosed sponsorship, current trends, or future performance claims.

The current checkout contains the Gold manifest but neither Gold Parquet payload nor the builder's historical input directories. Therefore historical preservation, Gold checksum integrity, and real-corpus runtime behavior are **not verified in this environment**. This finding concerns the current checkout; it does not establish whether the owner retains backups elsewhere.

## Practical data sequence

1. Restore and verify the existing historical inputs and Gold payloads, preserving originals. Record precise counts, logical bytes, hashes, source revision, observation time, and schema versions before making reproducibility claims.
2. Complete a historical descriptive MVP: metadata analytics, retrieval over available text, citation-grounded script assistance, explicit old-data dates, and manually checked retrieval evaluation. Keep selected/high-view transcript coverage visible.
3. Collect a deliberately bounded fresh dataset for audio and comments. Measure actual acquisition/ASR CPU costs and failure rates; manually annotate a test slice before estimating ABSA, duplicate-comment, prosody or sponsorship quality.
4. Add trust and multimodal modules only to the extent supported by those new measurements. Grounded citations and heuristic flags are useful demonstration outputs; they do not independently establish deception, experience, or causal uplift.

## Method and limits

The recursive GitHub tree was inspected without truncation. Bounded first-1-MiB CSV reads were used for raw/schema samples; the complete 56.4 MB cleaned-video CSV supplied population aggregates. Four Parquet responses were held only in memory and capped at 16 MiB each; only their Thrift Compact footers were parsed. An initial suffix-range request returned HTTP 501, so no successful range-read claim is made. One transcript and one raw-video JSON were inspected for keys and types, with values and creator-specific paths excluded from stored evidence. The complete historical raw corpus, all transcripts, original human labels, original collection permissions and any owner backups were not exhaustively inspected.
